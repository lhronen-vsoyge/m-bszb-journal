# m-bszb-journal

## 项目简介

`m-bszb-journal` 是一个用于归档和发布多个独立 HTML 页面的仓库。本项目不针对任何特定网站或域名，仅作为静态页面的存储与展示空间。

## 目录说明

```
/
├── index.html          # 项目首页，提供入口导航
├── pages/              # 存放所有归档的 HTML 页面
│   ├── example-page1.html
│   ├── example-page2.html
│   └── ...
├── assets/             # 公共资源文件（CSS、JS、图片等）
│   ├── css/
│   ├── js/
│   └── images/
└── README.md           # 本文件
```

## 页面归档说明

- 所有归档页面均为独立的 HTML 文件，存放在 `pages/` 目录下。
- 页面资源（样式、脚本、图片等）建议存放于 `assets/` 目录，便于统一管理。
- 每个页面应保持结构完整，确保在浏览器中可直接打开访问。
- 归档页面内容不涉及具体域名或网站，仅供存档与展示用途。

## 维护说明

1. **新增页面**：在 `pages/` 目录下创建新的 HTML 文件，并更新 `index.html` 中的导航链接。
2. **资源更新**：如需更新公共资源，请修改 `assets/` 下的对应文件，注意保持向后兼容。
3. **删除页面**：从 `pages/` 中移除文件，并同步更新 `index.html` 中的导航。
4. **版本管理**：建议为每次重要更新打标签（tag），便于回溯历史版本。

## 使用方式

可通过 GitHub Pages 或其他静态托管服务直接部署本仓库，访问 `index.html` 即可浏览所有归档页面。具体部署方式请参考对应托管平台的文档。

## 许可

本项目仅用于页面归档与展示，不提供任何形式的保证。如需引用或修改，请自行评估风险。
